# 🌳 線上公園

一個麥塊風格的多人線上公園網頁遊戲。帶上你的紙箱，找個位子躺一下，還能跟其他人聊天。

## 執行方式

```bash
cd online-park
npm install
npm start
```

然後用瀏覽器開啟 **http://localhost:3000**（可開多個分頁模擬多人）。

## 操作

| 按鍵 | 功能 |
|------|------|
| WASD | 移動 |
| 空格 | 跳躍 |
| 滑鼠拖曳 | 轉視角 |
| **B** | 在前方放下／收起自己的紙箱 |
| **L** | 躺進紙箱／起來 |
| Enter | 開始聊天（Esc 結束） |

## 功能

- 輸入名字即可登入，無需帳號
- 方塊風公園：草地、樹、小花、長椅
- 第三人稱視角，看到自己和其他玩家
- 每個玩家可帶自己的紙箱，鋪在地上躺著
- 左下角簡易聊天室，進出公園會有系統通知

## 技術

- Node.js + `ws`（WebSocket 多人同步）
- Three.js（CDN 載入，方塊風 3D 場景）
- 純靜態前端，無需建置

## 之後可以加

- 紙箱拖曳到任意位置
- 更多道具（涼傘、西瓜、腳踏車）
- 公園地圖擴大、水池
- 表情動作（揮手、比讚）
